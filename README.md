# AI Event Feedback Generator

## Problem
Creating customized feedback forms for different events is repetitive and often produces generic questions.

## Solution
This automation takes an event description, uses Google Gemini to generate event-specific feedback questions, and then automatically creates a Google Form.

## Workflow

Event Description
→ n8n Form Trigger
→ Google Gemini
→ JSON Parsing
→ Google Apps Script
→ Google Form

## Tools
- n8n
- Google Gemini
- Google Apps Script
- Google Forms
